COMPARING THE TWO LIVE BUS FEEDS OF DELHI
====================================================================================================
  Both feeds give a GTFS-Realtime VehiclePositions file: one entry per bus with its position and
  some details. This script downloads both, reads every field, and shows what each feed has and
  what it does not have. Names used below: OTD = otd.delhi.gov.in, TStack = Delhi Transport Stack.

====================================================================================================
7. DO THE FEEDS DESCRIBE THE SAME BUSES?
====================================================================================================
  Buses are matched by id. The script tries every pair of id fields (vehicle.id, vehicle.label,
  vehicle.license_plate, entity id) and uses the pair with most buses in common.
  OTD buses: 3,573   TStack buses: 3,573
  example ids in OTD: ['DL51EV2592', 'DL51EV0534', 'DL1PD4369', 'DL1PD9174']
  example ids in TStack: ['DL51EV0534', 'DL1PD8718', 'DL1PD7602', 'DL1PD9773']
  best match: OTD 'vehicle.id' = TStack 'vehicle.id'. In both: 3,573  | only in OTD: 0  | only in TStack: 0
  So TStack has 100% of the OTD buses, and OTD has 100% of the TStack buses.
  distance between the two positions of the same bus: median 61 m, 90th pct 265 m, largest 2,990 m
  timestamp difference (TStack minus OTD): median -11 s | TStack newer for 0%, same for 6%, older for 94%
  A positive difference means TStack has a newer ping of that bus. (The two downloads are about a
  second apart, so small differences are normal.)

  fields that exist in both feeds: do the values agree for the same bus?
  field                       buses compared  same value
  --------------------------  --------------  ----------
  position.speed              3573            7%        
  trip.route_id               3573            100%      
  trip.schedule_relationship  3573            77%

  trip.start_time             3573            3%        
  trip.trip_id                3573            0%        
  vehicle.id                  3573            100%      
  vehicle.label               3573            100%      
  A low 'same value' means the two feeds use different formats for that field (for example
  different route ids). Look at the samples in section 9.

10. SUMMARY: WHAT THE TWO FEEDS GIVE
====================================================================================================
  Fields only in OTD: none
  Fields only in TStack: none
  Fields in both: position.latitude, position.longitude, position.speed, timestamp, trip.route_id,
  trip.schedule_relationship, trip.start_date, trip.start_time, trip.trip_id, vehicle.id,
  vehicle.label
  Fields that carry real information in TStack but not in OTD: position.speed

  What this means for the project:
    - TStack gives a real speed value: use it directly (and compare with the speed worked out from
    positions).

  Next steps: (1) run this once during peak hours and once at night, the answer can differ. (2)
  Run with --polls 4 --interval 15 to compare how often each feed changes. (3) If TStack has
  fields or buses that OTD lacks, we can add it as a second source to the collector.
